# Project 1 – Rule-Based AI Chatbot

## Overview

This project was developed as part of the DecodeLabs AI Internship. The goal was to build a simple rule-based chatbot in Python that responds to predefined user inputs.

The chatbot uses basic programming logic rather than machine learning. It accepts user input, checks it against a set of predefined responses, and continues the conversation until the user chooses to exit.

## Objectives

The main objectives of this project are:

- Build a simple chatbot using Python.
- Respond to predefined user inputs.
- Handle unknown inputs with a default response.
- Keep the chatbot running until the user exits.
- Demonstrate the use of rule-based decision making.

## Features

- Responds to greetings such as "hello" and "hi".
- Answers a small set of predefined questions.
- Displays a default message for unknown inputs.
- Supports multiple exit commands such as `bye`, `exit`, and `quit`.
- Runs continuously using a loop until the user ends the conversation.
